# Re:ZERO 异世界灵魂属性测试（36角色 · 含监视塔与大罪IF线）

基于《Re:从零开始的异世界生活》（Re:Zero）世界观打造的直觉向灵魂属性与精神状态测试 Web 应用。通过 **20 道去冒犯化、高区分度的日常与异世界情境题**，结合 **五维灵魂向量投影 + 角色直连权重双轨 Z-Score 校准算法**，精准测出你的本命主线角色、副人格以及黑化/镜像 IF 线结局。

  - **菜月昴 · 大罪 IF 线（5 人）**：傲慢 IF（溺于火海）、强欲 IF（数亿次完美复盘）、愤怒 IF（肃清王）、怠惰 IF（卡拉拉基浪人）、暴食 IF（死者之书拼图者）。
- **定制无背景 Q 版角色立绘（`ChibiCharacterArt.tsx`）**：
  - 严格对照 `re0-36-portraits/` 中的 36 张角色正面立绘参考图（官方 TV 动画人设图、Dengeki 插画及 IF 线经典设定图），逐一还原每位角色的标志性发型、瞳色（含罗兹瓦尔蓝黄异瞳、暴食 IF 昴金灰异瞳、艾姬多娜白睫毛等）、发饰与代表性服饰。
- **双轨 Z-Score 反中心偏差算法（`quizEngine.ts`）**：
  - 针对 36 角色在五维空间（`死磕指数`、`精神稳定`、`发疯狠度`、`护短浓度`、`嘴硬整活`）中的分布差异，预计算每个角色在 20 道题上的解析均值与标准差：
    $$\text{CompositeZ}_i = 0.72 \times Z_{\text{direct}, i} + 0.38 \times Z_{\text{traitProj}, i}$$
  - 彻底消除传统欧氏距离对“五维均值型角色”的中心引力偏差（Hubness Bias），确保全部 36 位角色在蒙特卡洛随机模拟中命中率均衡分布在 `1.3% ~ 4.6%` 之间，且每名角色均有 `100%` 专属必中答题路径。
- **自然去冒犯的 20 题设计**：
  - 摒弃极端反社会或令人不适的冒犯性选项，所有题目均提供 4 个动机合理、价值感对等、互不重叠的性格切面。
- **移动端优先（Mobile-First）体验与一键分享**：
  - 紧凑顶栏、拇指热区底部操作栏、全屏列表/详情自适应切换的 36 角色图鉴，以及免输入昵称的一键战报分享弹窗。

```bash
npm install
npm run dev
```
开发服务器默认监听 `http://localhost:3000`。

```bash
npx --yes tsx --test src/utils/quizEngine.test.ts
```

- 36 位角色数据完整性、五维坐标唯一性；
- 20 道题目、80 个选项结构完整性与去冒犯化平衡性；
- 全部 36 位角色各自的专属必中路径（`100%` 命中率）；
- 蒙特卡洛均匀随机采样下 36 位角色的全局分布均衡性。
